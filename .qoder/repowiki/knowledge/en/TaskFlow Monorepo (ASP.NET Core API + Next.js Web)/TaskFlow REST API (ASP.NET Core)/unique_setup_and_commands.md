Requires .NET 10 SDK, a running PostgreSQL server, and `dotnet-ef` 10.x (`dotnet tool install --global dotnet-ef --version 10.0.12`). From `Services/`: `dotnet restore Services.slnx`, then `dotnet ef database update --project Services.Infrastructure --startup-project Services.Api -- --environment Development`, then `dotnet run --project Services.Api --launch-profile https`. Development secrets are configured via `dotnet user-secrets` for `ConnectionStrings:DefaultConnection`, `Jwt:Issuer`, `Jwt:Audience`, `Jwt:SecretKey` (Base64 ≥ 32 bytes), and `Jwt:ExpirationMinutes` (positive). The `https` launch profile exposes `https://localhost:7120` and `http://localhost:5020`; `/scalar/v1` and `/openapi/v1.json` are available in Development.
