Two independent runtime consumers share one data plane: the .NET solution under `Services/` (API, Application, Domain, Infrastructure layers) exposes a REST API over HTTPS, while the Next.js app under `Apps/Web/` consumes it as an HTTP client. Both depend on a single PostgreSQL instance configured via User Secrets (`ConnectionStrings:DefaultConnection`) and authenticate requests with a JWT secret (`Jwt:SecretKey`). There are no shared libraries between children; integration is purely HTTP + database, with the root README serving as the only cross-cutting entry point documenting prerequisites and the end-to-end bootstrap sequence.
