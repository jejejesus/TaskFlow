Two independent runtime consumers share one data plane: the .NET solution under `Services/` (API, Application, Domain, Infrastructure layers) exposes a REST API over HTTPS, while the Next.js app under `Apps/Web/` consumes it as a client. Both depend on a single PostgreSQL instance configured via User Secrets (`ConnectionStrings:DefaultConnection`) and authenticate requests with a JWT secret (`Jwt:SecretKey`). The root README is the only cross-cutting entry point — it documents prerequisites (.NET 10 + EF Core tools, Node ≥20.9, pnpm), the local bootstrap sequence (restore → `dotnet ef database update` → `dotnet run` for the API, then `pnpm install && pnpm dev` for the web), and the default URLs (`https://localhost:7120/api` for the API, `http://localhost:3000` for the web). There are no shared libraries between children; integration is purely HTTP + database.
