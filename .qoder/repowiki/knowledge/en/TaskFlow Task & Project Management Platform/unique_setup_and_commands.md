Local bootstrap from `Services/`: `dotnet restore Services.slnx`, `dotnet ef database update --project Services.Infrastructure --startup-project Services.Api -- --environment Development`, `dotnet run --project Services.Api --launch-profile https`; then from `Apps/Web/`: `pnpm install && pnpm dev`. API base URL defaults to `https://localhost:7120/api` and can be overridden via `Apps/Web/.env.local` `API_BASE_URL`.
